# 🍚 시골 마루의 밥알 세기 (Count Rice Game)

> **"화창한 날 햇살과 강바람 아래, 젓가락으로 여유롭게 밥알을 세어보세요."**  
> 평온한 시골집 툇마루에 앉아 새소리, 시냇물 소리, 그리고 똥강아지 짖는 소리를 들으며 즐기는 힐링 밥알 카운팅 웹 게임입니다.

---

## ✨ 게임 특징

1. **밥 한 공기 분량의 무작위 밥알 생성**
   - 어른 밥 한 공기 기준 **약 1,900 ~ 2,500알**이 매번 완전 무작위로 생성됩니다.
   - 맛보기 한 숟갈(~120알), 어린이 공기(~600알), 어른 밥 한 공기(~2,200알), 고봉 머슴밥(~3,800알) 크기 선택 지원.
   - `[새 밥 짓기 🔄]` 버튼으로 언제든 새로운 밥으로 리필 가능!

2. **정밀한 젓가락 커서 & 밥알 인터랙션**
   - 마우스 커서가 전통 원목 젓가락으로 변경되며, 클릭 시 두 젓가락이 오므려지는 찝기(Pinch) 모션.
   - 젓가락 끝으로 밥알을 클릭하면 **밥알 1알이 젓가락 끝에 쏙 집히며**, 밥그릇 밖 식탁 위에 자유롭게 덜어놓으며 셀 수 있습니다.
   - 클릭한 밥알은 은은한 황금빛 체크 표시가 남아 세었던 밥알을 쉽게 구분할 수 있습니다.

3. **밥그릇 클릭/이동 고정 (Lock) 기능**
   - 상단의 `[🔓 밥그릇 이동 가능]` 버튼을 누르면 `[🔒 밥그릇 고정됨]` 상태로 전환됩니다.
   - 밥알을 집을 때 밥그릇이 실수로 움직이지 않도록 단단히 고정하여 밥알 세기에만 100% 집중할 수 있습니다.

4. **제한시간 없는 정답 맞추기 & 폭죽 축하 연출**
   - 시간제한 없이 느긋하게 숫자를 입력하여 확인 가능.
   - 틀려도 무제한으로 계속 입력할 수 있으며, `UP 🔼 / DOWN 🔽` 힌트 제공.
   - 정답을 맞추면 축하 팡파레와 함께 화면 가득 화려한 **불꽃놀이 폭죽(Fireworks)**과 꽃가루가 연쇄 폭발합니다!

5. **자체 합성 Web Audio 힐링 사운드 (외부 파일 의존 없음)**
   - 평화로운 시골 어쿠스틱/칼림바 선율 BGM
   - 졸졸졸 시원하게 흐르는 강물/시냇물 소리
   - 짹짹 지저귀는 시골 참새/산새 소리
   - 살랑살랑 부는 산들바람 소리
   - **14~30초마다 멀리서 정겹게 울려 퍼지는 시골집 누렁이 똥강아지 짖는 소리 ("멍! 멍!")**
   - 볼륨 슬라이더 및 음소거 On/Off 토글 지원

6. **아름다운 시골 풍경 비주얼**
   - 푸른 하늘, 눈부신 햇살과 뭉게구름, 날아가는 제비
   - 짙푸른 소나무 숲 군락과 커다란 시골 정자나무
   - 싱그러운 계단식 논밭과 정겨운 밀짚모자 허수아비
   - 맑은 강물 위 둥실둥실 떠 있는 나무 나룻배(조각배)와 갈대숲
   - 시골집 굴뚝 연기, 장독대 항아리, 해바라기/코스모스 들꽃 정원
   - 마루 옆 마당에서 낮잠 자며 꼬리 흔드는 시골 똥강아지

## 🚀 GitHub 업로드 및 Vercel 배포 가이드

이 프로젝트는 순수 정적 웹(HTML5, CSS3, Vanilla JS, Web Audio API)으로 제작되어 **별도의 빌드 과정 없이 Vercel에서 즉시 100% 무료 배포**됩니다.

### 1단계: GitHub에 저장소 만들기
1. [GitHub](https://github.com/)에 로그인 후 우측 상단의 **[+] → [New repository]** 클릭.
2. 저장소 이름(Repository name)에 `count-rice` 입력.
3. 공개 범위(Public) 선택 후 **[Create repository]** 버튼 클릭.

### 2단계: 로컬 코드를 GitHub에 푸시(Push)
이 프로젝트 폴더(`c:\Users\PC\Desktop\count-rice`)에서 터미널(Git Bash 또는 PowerShell)을 열고 아래 명령어를 순서대로 실행합니다:

```bash
# 1. 깃 저장소 초기화
git init

# 2. 파일 추가 및 첫 커밋 생성
git add .
git commit -m "feat: 시골 마루의 밥알 세기 힐링 게임 완성본"

# 3. 기본 브랜치를 main으로 설정
git branch -M main

# 4. 방금 만든 내 GitHub 저장소 주소 연결 (YOUR_USERNAME 부분을 본인 아이디로 변경)
git remote add origin https://github.com/YOUR_USERNAME/count-rice.git

# 5. GitHub에 푸시
git push -u origin main
```

---

### 3단계: Vercel에서 1분 만에 배포하기
1. [Vercel](https://vercel.com/)에 접속하여 GitHub 계정으로 로그인합니다.
2. 대시보드 우측 상단의 **[Add New...] → [Project]**를 클릭합니다.
3. 방금 푸시한 **`count-rice`** 저장소 옆의 **[Import]** 버튼을 클릭합니다.
4. 설정 화면:
   - **Framework Preset**: `Other` (기본값 그대로 둠)
   - **Root Directory**: `./` (기본값 그대로 둠)
   - **Build and Output Settings**: 수정할 필요 없음 (자동 인식)
5. 파란색 **[Deploy]** 버튼을 누릅니다!
6. 약 15초~30초 후 축하 폭죽과 함께 **배포 완료(Congratulations!)** 화면이 나타나며, 전 세계 어디서든 접속 가능한 나만의 게임 링크(`https://count-rice-xxxx.vercel.app`)가 생성됩니다! 🎉
